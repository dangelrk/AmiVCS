# Historische Planungsdokumente

Die Dateien in diesem Verzeichnis stammen aus der Planungsphase, als
AmiVCS noch Teil des gemeinsamen Monorepos „AmiCloud“ war. Sie werden
bewusst nicht aktualisiert: Pfade darin (z. B. `client/apps/`, `libs/`,
`amivcs-server/`, `docs/architecture/`) beziehen sich auf die alte
Struktur, und einzelne Entscheidungen (etwa „kein Staging-Bereich“) sind
inzwischen überholt. Den aktuellen Stand beschreiben die
[README](../../README.md), [BUILD.md](../BUILD.md),
[INSTALL.md](../INSTALL.md) und das Handbuch unter [docs/user/](../user/).
